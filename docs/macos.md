# Самостоятельное приложение для macOS

Текущая версия — `dist/Семестр.app`. Внутри: Swift/AppKit, системный WKWebView, встроенные React-ресурсы и SQLite из macOS. При запуске не поднимаются сервер, контейнер или браузер. Никаких дополнительных сред выполнения устанавливать не нужно.

## Запуск и хранение

Откройте `.app` двойным щелчком. Приложение сразу создаёт локальное пространство; вход и email не требуются. База хранится в `~/Library/Application Support/Semestr/semestr.sqlite3`. Каталог принадлежит пользователю Mac; SQLite использует WAL и транзакции. Каждая запись имеет версию, устаревшие изменения отклоняются.

База хранит нормализованный документ рабочего пространства в SQLite. Это упрощает атомарный импорт и небольшое личное хранилище. При больших объёмах потребуется переход к отдельным таблицам и виртуализация интерфейса; текущая защитная граница — 10 000 учебных записей.

Для переноса и резервного копирования используйте JSON-экспорт. При импорте сначала показывается состав файла. «Добавить» переназначает идентификаторы, сохраняя связи; «Заменить» требует явного подтверждения. Если данные изменились после предпросмотра, импорт отклоняется до повторной проверки. Замена сборки приложения не затрагивает базу.

Начиная с 0.3 тема хранится в SQLite вместе с профилем. При первом запуске обновлённая версия подхватывает прежнюю тему из WebKit. Черновики форм остаются в локальном WebKit-хранилище и не входят в JSON-экспорт. Синхронизации с серверной версией или другим Mac нет.

### Перенос только настроек

«Настройки → Перенос настроек» сохраняет отдельный JSON-файл. Он содержит `format: "semestr-settings"`, `formatVersion: 1`, `profile` и `appearance.theme`. Ограничение размера — 64 КБ; неизвестные поля, темы и неподдерживаемые версии отклоняются. Идентификатор аккаунта, пути, черновики и учебные записи в файл не включаются.

Файл можно загрузить в приложение 0.3+ на другом Mac под другой учётной записью. Сначала показывается профиль и тема из файла. Кнопка «Применить настройки» заменяет профиль и оформление одной транзакцией, сохраняет идентификатор аккаунта получателя и все учебные записи. Проверка ревизии защищает от применения устаревшего предпросмотра. Тема и профиль сохраняются после перезапуска.

Системные окна выбора/сохранения файла доступны через нативный мост; JavaScript не задаёт путь к файлу. В UI-тесте только выбор пути заменяется временным тестовым каталогом: запись, чтение, проверка формата, предпросмотр и применение выполняются настоящим кодом приложения.

## Долг без предварительного создания предмета

В версии 0.3.1 форма нового академического долга по умолчанию предлагает ввести название нового предмета. Достаточно названия; «Академическая разница» и «Уточнить требования» выставляются автоматически. Дополнительные поля можно раскрыть или заполнить позже. Существующий предмет выбирается отдельным режимом, а совпадающее название даёт подсказку для повторного использования.

Нативная операция `POST /debts/with-subject` принимает название и данные долга. Проверяет обе записи, связывает их и сохраняет одной транзакцией SQLite. При ошибке не остаётся незаполненного предмета. Черновик формы включает название и режим выбора. После сохранения открываются долги и досье нужного предмета.

## Команды Mac

- `⌘N` — новый предмет.
- `⌘E` — экспорт через стандартное окно сохранения.
- `⌘W` — закрыть окно и завершить приложение.
- `⌘Q` — завершить приложение.
- Ссылки на материалы и пары открываются в браузере по умолчанию.

Нативный мост принимает команды только из основного локального документа внутри app bundle. Разрешены операции с собственной базой, копирование текста и системные диалоги выбора/сохранения файла. Произвольные команды и пути из JavaScript не выполняются. В интерфейсе нет загрузки внешних шрифтов, аналитики или фоновых сетевых запросов.

## Сборка

Требуются macOS 13+, Xcode Command Line Tools, Node.js 22.13+ и pnpm 11.25.0:

```sh
pnpm install --frozen-lockfile
pnpm desktop:build
open dist/Семестр.app
```

`scripts/build-macos.sh` собирает ресурсы и Swift для архитектуры текущего Mac, выполняет проверки базы на временных данных, создаёт `.icns` и подписывает сборку ad-hoc. Для универсальных DMG/ZIP выполните `pnpm desktop:release`. Публичные сборки доступны в [Releases](https://github.com/Melnk/semestr/releases); они пока без Developer ID/notarization и могут потребовать подтверждения первого открытия. Защитные настройки macOS скрипт не меняет.

Для регрессии:

```sh
pnpm test
pnpm desktop:test
SEMESTR_TEST_OUTPUT="$PWD/artifacts" dist/Семестр.app/Contents/MacOS/Semestr --ui-test
```

Последняя команда открывает тестовое окно с временной базой, проверяет отрисовку и связь интерфейса с SQLite, сохраняет снимок и завершает процесс. Пользовательское пространство не открывается.

## Отдельная веб-версия

Серверная версия сохранена в `backend` и `infra`, но не участвует в запуске `.app`. Прежняя Tauri-оболочка в `apps/desktop` подключалась к серверу и не является текущим приложением Mac. Скрипты `desktop:build` и `desktop:dev` теперь используют Swift-сборку.
