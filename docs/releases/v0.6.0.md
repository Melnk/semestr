Новый раздел **«Задания»** в боковом меню собирает домашки по всем предметам в одном месте.

- Задания отсортированы по дедлайну: сначала ранние сроки, без срока — в конце.
- У каждой работы видны предмет, статус, дата и время. Просроченные отмечены отдельно; принятые не помечаются просроченными.
- Поиск работает по названию задания и предмета. Есть фильтры «Все», «Открытые» и «Принятые».
- Можно добавить домашку или открыть её для редактирования прямо из списка. После изменения дедлайна порядок обновится.
- Домашки по академической разнице тоже включены. Счётчик в меню показывает число открытых заданий.
