В «Семестре» появилась проверка обновлений:

- Раз в сутки при открытом приложении; автоматическую проверку можно отключить.
- Кнопка «Проверить обновление» в настройках и меню приложения.
- Плашка новой версии с кнопкой «Обновить» и ссылкой на список изменений.
- Скачивание DMG, проверка контрольной суммы и открытие установщика. Данные и настройки сохраняются при замене приложения.

Для завершения обновления закройте «Семестр» и перенесите новую версию в «Программы» с заменой. Из версии 0.4.1 и ниже эту сборку нужно скачать вручную; следующие релизы приложение найдёт само.
