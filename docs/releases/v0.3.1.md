Первый публичный релиз «Семестра» — бесплатного приложения для учёбы на Mac.

## Скачать и установить

**[Скачать для Mac (.dmg)](https://github.com/Melnk/semestr/releases/download/v0.3.1/Semestr-macOS-universal.dmg)** · [ZIP](https://github.com/Melnk/semestr/releases/download/v0.3.1/Semestr-macOS-universal.zip)

macOS 13 и новее. Один файл для Apple Silicon и Intel. Откройте DMG, перенесите «Семестр.app» в «Программы» и запустите. Docker, сервер, регистрация и подписка не нужны.

Релиз без Developer ID и нотариализации Apple. При предупреждении о непроверенном разработчике можно подтвердить открытие именно этого приложения в «Системные настройки → Конфиденциальность и безопасность», если вы доверяете релизу. [Инструкция Apple](https://support.apple.com/ru-ru/102445). На управляемом компьютере эта возможность определяется политиками ИТ-отдела.

## Возможности

- Предметы, задания, академические долги, заметки и полезные ссылки.
- Долг по новому предмету: достаточно ввести название; предмет создаётся автоматически.
- Расписание, чётность недель, часовые пояса, переносы и отмены отдельных пар.
- Светлая/тёмная тема, поиск, архив, копирование контекста.
- Локальная SQLite-база, JSON-экспорт/импорт и перенос настроек между аккаунтами.

Данные сохраняются на компьютере. Автоматической синхронизации и автообновления пока нет. Для новой версии достаточно заменить приложение; база хранится отдельно. Это первая публичная версия, обратную связь можно оставить в [Issues](https://github.com/Melnk/semestr/issues).

В комплекте есть контрольные суммы SHA-256. Исходники — под лицензией MIT.
