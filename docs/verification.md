# Проверки

## Самостоятельное приложение Mac — текущая версия 0.3.1

Проверено на этом Mac 7 октября 2026, с остановленными Docker/Colima и Kotlin/Vite:

- `pnpm desktop:build`: production-интерфейс и Swift для текущей архитектуры, системная иконка, bundle `dist/Семестр.app`, ad-hoc подпись и `codesign --verify --strict`.
- 80 проверок нативной SQLite-базы: открытие без регистрации, сохранение и повторное открытие базы, версии профиля и записей, защита связей, состояния заданий и долгов, пагинация, расписание и чётность, полночь, DST, пересечения, перенос/отмена/восстановление, атомарный импорт, подтверждение замены и переназначение идентификаторов. Добавлен перенос файла настроек между двумя независимыми аккаунтами: сохранение аккаунта и всех записей получателя, повторное открытие базы, сохранение темы, конфликты предпросмотра и отказ на некорректных файлах.
- Создание предмета вместе с академическим долгом: только название в пустой базе, сохранение пары одной транзакцией, неверные даты и статусы без пустого предмета, сохранение дополнительных полей, независимость от ранее выбранного предмета, повторное открытие базы.
- 3 клиентских теста: состав копируемого контекста, разбиение занятия по полуночи и раскладка пересечений.
- Реальное окно WKWebView (`--ui-test`): открытие формы командой меню, создание предмета и заметки через формы, чтение сохранённых данных из SQLite, навигация, сохранение профиля, светлая/тёмная тема, экспорт настроек в настоящий временный файл, изменение профиля, чтение файла, отмена предпросмотра и применение с проверкой сохранности записей. Добавлены ввод только названия предмета в форме долга, отмена без создания записей, восстановление названия из черновика, выбор существующего предмета по подсказке без дублирования. Тест использует отдельную временную базу и удаляет её.
- Во время сценария WebKit зарегистрировал **0 HTTP(S)-ресурсов**; интерфейс и шрифты работают локально. Визуально проверен снимок окна.

Автоматизированный сценарий подставляет временный путь вместо ручного выбора в системной панели. Запись и чтение файла настроек, его проверка, предпросмотр, отмена и применение проходят через настоящий нативный мост. Само ручное взаимодействие с системной панелью остаётся отдельной проверкой. Универсальный релиз скомпилирован для `arm64` и `x86_64`; образ DMG и подпись проверены. Интерфейс проверен на Apple Silicon. Developer ID, нотариализация и запуск интерфейса на физическом Intel Mac не проверялись.

## Прежняя серверная версия 0.1

Проверено на этом Mac 7 октября 2026. Проверки выполнялись с настоящими Kotlin/Spring Boot API, PostgreSQL 17.11 и Mailpit в локальной Colima. Деморежим не использовался вместо проверки серверного сохранения.

## Успешно

- Production-сборка React/TypeScript (`pnpm build`).
- Воспроизводимая установка по `pnpm-lock.yaml`.
- Maven package с 8 тестами: DST, переход через полночь, чётность, политика неоднозначного времени, закрытие долга, состояния заданий, безопасные ссылки и ограничения расписания.
- 3 клиентских теста: полнота контекста, разбиение события по локальной полуночи, расположение цепочки пересечений.
- 27 сценариев `scripts/smoke.py`: регистрация/подтверждение двух пользователей, одноразовость токена, cookie+CSRF и bearer-вход, изоляция чтения и создания связей, чужой долг/предмет, связь с неправильным собственным предметом, второе устройство, конфликты записи/профиля/исключения, задания/долги, UTC и чётность, перенос/отмена/восстановление, пересечения, экспорт, предпросмотр, атомарный некорректный импорт, подтверждение/ревизия замены, замена/добавление с переназначением ID, пагинация, сброс пароля с отзывом сессий, выход, удаление аккаунта и связанных записей.
- В браузере: реальный вход, загрузка сохранённых предметов, создание и чтение заметки, навигация и вкладки досье, недельная временная сетка с занятием и дедлайном, тема.
- Экран 390 × 844: ширина документа 390, горизонтальная прокрутка отсутствует; досье открывается отдельным экраном. На компьютере — три колонки.
- Сервер намеренно остановлен: сохранение показало ошибку, форма осталась открыта; после закрытия и открытия восстановлен тот же текст локального черновика. Сервер впоследствии остановлен при переходе на самостоятельное приложение.
- Docker Compose config и синтаксис локального shell-скрипта.
- OpenAPI выгружен с работающего сервера; TypeScript DTO генерируются и используются API-клиентом.

Тестовые API-аккаунты удаляются smoke-скриптом. Дополнительный тестовый UI-аккаунт удалён после браузерной проверки. В приложении остаётся отдельный публичный деморежим с вымышленными данными.

## Ограничения прежней серверной версии

- Старый вариант Tauri не собирался. Текущее самостоятельное приложение использует Swift/AppKit; его проверки описаны отдельно выше.
- История проверок в GitHub доступна в [Actions](https://github.com/Melnk/semestr/actions).
- PostgreSQL/Mailpit запущены реальными контейнерами; полная сборка Docker-образов web/backend не выполнялась. Compose валидирован, приложение отдельно собиралось/работало на хосте.
- Публичный HTTPS-сервер, настоящая доставка SMTP, backup/restore на отдельной машине, нагрузка и независимый аудит безопасности не проверены.
- Полной офлайн-синхронизации нет. Черновики покрывают учебные формы; профиль, пароли, импорт и переносы не сохраняются в локальные черновики.
- Обновление другого устройства — polling раз в 20 секунд и при возврате в окно, не мгновенные push-события.
- API поддерживает пагинацию; UI пока загружает все страницы. Нет виртуализации/серверного полнотекстового поиска, вложенных файлов, уведомлений или iOS-клиента.
- Тексты и преподаватели в демо вымышлены. Скриншот-референс и пользовательское техническое задание не копировались в публичные файлы.

Эти ограничения означают готовую к локальному использованию первую веб-версию, а не заявление о проверенной промышленной эксплуатации всех платформ.
