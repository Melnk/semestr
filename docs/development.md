# Локальная разработка

Для приложения Mac используйте команды в README. Этот раздел относится к отдельной веб-версии: нужны Node.js 22.13+, pnpm 11.25.0, JDK 21, Maven и Docker с PostgreSQL/Mailpit. На локальном Mac, где эти инструменты уже установлены, можно использовать вспомогательный скрипт:

```sh
./scripts/dev-local.sh
```

Скрипт проверяет инструменты, использует текущий Docker либо существующую Colima, запускает **только** контейнеры `semestr-db` и `semestr-mail`. Если 8080 уже обслуживает Семестр, повторно сервер не запускается. Если 5173 уже занят этим веб-клиентом, скрипт сообщает URL. Логи и Maven cache лежат в игнорируемой `.local/`. `Ctrl+C` останавливает только процессы сервера/клиента, запущенные этой копией скрипта, контейнеры сохраняются.

Адреса:

| Назначение | Адрес |
|---|---|
| Веб | http://localhost:5173 |
| Демо, только просмотр | http://localhost:5173/?demo=1 |
| API | http://localhost:8080/api/v1 |
| Документация | http://localhost:8080/swagger-ui/index.html |
| Тестовая почта | http://localhost:8025 |
| PostgreSQL | localhost:54329 |

Учётные данные локальной БД — в `.env.example`; они применимы только к локальному окружению. Для реального размещения замените их. Данные БД лежат в Docker volume, не в Git.

При конфликте портов не завершайте неизвестные процессы. Остановите собственный предыдущий запуск или измените порты, APP_ORIGIN и Vite proxy согласованно.

## Остановка инфраструктуры

Для Compose: `docker compose -f infra/compose.yml stop`. Для локального скрипта: `docker stop semestr-db semestr-mail`. Эти команды сохраняют данные. Не добавляйте `down -v`, если данные нужны.

Для изменения JDK задайте JAVA_HOME. Maven cache по умолчанию `~/.m2`; скрипт для этой рабочей копии использует `.local/m2`.

## Письма

Mailpit принимает письма на 1025, интерфейс на 8025. Ссылка из письма открывает форму подтверждения или восстановления. В production настройте собственный SMTP и HTTPS origin; никакие реальные адреса/SMTP-секреты не включены в код.
