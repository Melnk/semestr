СЕМЕСТР — МЕНЕДЖЕР УЧЁБЫ
https://github.com/Melnk/semestr

macOS 13 и новее. Одна сборка для Apple Silicon и Intel.

1. Перетащите «Семестр.app» в папку «Программы».
   Можно также скопировать его в собственную папку ~/Applications.
2. Откройте приложение из выбранной папки.
3. В настройках укажите семестр и часовой пояс. Для нового академического
   долга достаточно ввести название предмета.

ПЕРВОЕ ОТКРЫТИЕ
В этой версии нет подписи Apple Developer ID и нотариализации Apple.
Если macOS сообщает, что разработчика не удалось проверить, после попытки
запуска откройте «Системные настройки → Конфиденциальность и безопасность»
и подтвердите открытие именно «Семестра», если доверяете этому релизу.
Официальная инструкция Apple: https://support.apple.com/ru-ru/102445
На управляемом рабочем Mac такое подтверждение может быть недоступно;
в этом случае действуют правила вашего ИТ-отдела.

ДАННЫЕ
Приложение работает без Docker, сервера и регистрации.
База хранится в ~/Library/Application Support/Semestr/semestr.sqlite3.
Для резервных копий: «Настройки → Ваши данные — с вами → Экспортировать».
Для переноса профиля и темы: «Настройки → Перенос настроек».
Обновление самого приложения сохраняет учебные записи.

Исходники и сообщения об ошибках: https://github.com/Melnk/semestr
Лицензия MIT. Новые версии проверяются раз в сутки при открытом приложении.
В «Настройках → Обновления приложения» можно проверить вручную или отключить
ежедневную проверку. «Обновить» скачает и откроет установщик; затем закройте
прежний «Семестр» и замените приложение. Данные и настройки сохранятся.
