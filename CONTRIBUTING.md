# Участие в разработке

1. Создайте ветку, опишите конкретный сценарий и ожидаемое поведение.
2. Для Mac выполните `pnpm desktop:build`; Docker не требуется. Используйте вымышленные данные. Для изменений локальной базы запускайте `pnpm desktop:test`; для интерфейса — `--ui-test` и `pnpm test`.
3. Для серверных изменений добавьте тест бизнес-правила или интеграционный сценарий. Любой запрос к данным должен иметь `user_id`; связи проверяются также по владельцу и предмету.
4. Изменения схемы БД вносите новой миграцией Flyway. Выполненные миграции не редактируйте.
5. При изменениях API обновите `docs/openapi.json` и `packages/api-client/src/schema.d.ts`. Старые native-клиенты могут использовать API v1: не ломайте его без новой версии.
6. Выполните сборку, тесты и smoke-проверку. Для UI проверьте телефон, клавиатуру, длинное название, пустое состояние и ошибку сохранения.
7. В PR укажите проблему, изменение поведения, проверки и ограничения. Не добавляйте реальные экспорты, `.env`, логи с секретами или пользовательские данные.

Код принимается на условиях MIT. Проект не содержит платных функций, тарифов и биллинга.
